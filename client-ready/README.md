# Client-Ready Portfolio Master Template

This folder is the editable master template for creating customized portfolio websites for multiple clients.

## Workflow
1. Keep this folder as the master template.
2. Duplicate it for each client.
3. Edit only `data/client.json` for most content changes.
4. Replace `assets/profile.jpg` and `assets/resume.pdf` when provided.
5. Adjust the theme variables in `styles.css` for design customization.
6. Deploy the client copy to a separate URL/domain.

## Included sections
- Master Template
- Client Details Form
- Client Copy Workflow
- Client Data Replacement
- Design Customization
- Deployment
- Payment Packages

Open `index.html` with a local web server to preview.
